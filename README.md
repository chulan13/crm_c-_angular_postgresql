# CRM-завдання

Невеликий застосунок для керування CRM-завданнями з API на ASP.NET Core 10, базою даних PostgreSQL та інтерфейсом на Angular 19. Інтерфейс використовує Angular `HttpClient`, стандартні елементи HTML і власні стилі CSS; бібліотеки UI-компонентів не використовуються.

## Вимоги

Встановіть на комп’ютер:

- Git
- .NET 10 SDK
- Node.js 20.11 або новішої версії (або сумісну новішу LTS-версію) і npm
- PostgreSQL, запущений локально або на доступному вам сервері

Перевірте встановлення .NET і Node.js:

```bash
dotnet --version
node --version
npm --version
```

## 1. Клонуйте репозиторій

```bash
git clone https://github.com/chulan13/crm_c-_postgresql_angular.git
cd crm_c-_postgresql_angular
```

## 2. Створіть базу даних PostgreSQL

Створіть базу даних із назвою `crm_tasks` за допомогою pgAdmin або `psql`. Наприклад, у pgAdmin під’єднайтеся до сервера PostgreSQL, відкрийте **Query Tool** для службової бази даних, наприклад `postgres`, і виконайте:

```sql
CREATE DATABASE crm_tasks;
```

Якщо використовуєте `psql`, виконайте:

```bash
createdb -U postgres crm_tasks
```

Якщо ім’я користувача PostgreSQL відрізняється, замініть `postgres` на своє. Якщо ви створили базу даних з іншою назвою, вкажіть цю назву в рядку підключення нижче.

## 3. Налаштуйте підключення до бази даних

Застосунок зчитує рядок підключення з .NET User Secrets, тому облікові дані не потрібно зберігати у файлах налаштувань, що відстежуються Git. Виконайте команду з кореневої папки репозиторію:

```bash
dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Host=localhost;Port=5432;Database=crm_tasks;Username=postgres;Password=YOUR_POSTGRES_PASSWORD"
```

Замініть `YOUR_POSTGRES_PASSWORD`, а за потреби — адресу сервера, порт, назву бази даних або ім’я користувача на відповідні значення вашого сервера PostgreSQL. Не додавайте паролі чи токени до репозиторію.

## 4. Запустіть API

Виконайте команду з кореневої папки репозиторію:

```bash
dotnet run
```

Під час першого запуску застосунок створює таблиці `CrmTasks`, `Departments` і `Statuses` у налаштованій порожній базі даних та імпортує приклади з файлів `testData/department.csv`, `testData/task_status.csv` і `testData/task.csv`. HTTP-профіль за замовчуванням доступний за адресою <http://localhost:5283>. Маршрути API: `/CrmTask`, `/Department` і `/Status`.

Для нового встановлення використовуйте окрему порожню базу даних. Застосунок створює схему, лише якщо база не містить таблиць. Він не оновлює наявну схему. Якщо таблиці CRM вже існують і містять дані, застосунок збереже ці дані та пропустить імпорт CSV-файлів.

## 5. Запустіть інтерфейс Angular

Відкрийте друге вікно термінала в кореневій папці репозиторію та встановіть залежності інтерфейсу відповідно до lock-файлу:

```bash
npm ci --prefix frontend
```

Після цього запустіть Angular:

```bash
npm start --prefix frontend
```

Відкрийте <http://localhost:4200>. Під час локальної розробки проксі Angular пересилає запити до API на `http://localhost:5283`. Поки користуєтеся інтерфейсом, API має працювати.

## Перевірте налаштування

В іншому вікні термінала перевірте, чи API повертає імпортовані дані:

```bash
curl http://localhost:5283/Status
curl http://localhost:5283/Department
curl http://localhost:5283/CrmTask
```

Можливі статуси: `Новий`, `В роботі`, `Виконано` та `Скасовано`. В інтерфейсі можна шукати й фільтрувати завдання, створювати, редагувати та видаляти їх. Для скасованого завдання потрібно вказати причину довжиною не більше ніж 250 символів.

## Усунення несправностей

- **Не вдається підключитися до бази даних:** Переконайтеся, що PostgreSQL запущений, а адреса сервера, порт, назва бази даних, ім’я користувача й пароль у User Secrets вказані правильно.
- **Інтерфейс не може підключитися до API:** Запустіть API на порту `5283`, як зазначено у `frontend/proxy.conf.json`, або змініть адресу проксі відповідно до порту API.
- **Порт уже використовується:** Зупиніть інший процес, який використовує порт `5283` або `4200`, або змініть відповідні налаштування запуску API, проксі чи Angular.

## Збирання проєкту

Зберіть API:

```bash
dotnet build
```

Зберіть інтерфейс:

```bash
npm run build --prefix frontend
```
