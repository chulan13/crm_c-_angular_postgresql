# Що реалізовано в проєкті

Цей проєкт - невеликий застосунок для щоденного керування робочими завданнями. Він поєднує API на ASP.NET Core, базу PostgreSQL та вебінтерфейс на Angular. Людина може переглядати завдання, знаходити потрібні, змінювати їх і стежити за термінами виконання.

## Робота із завданнями

На головній сторінці показано список завдань і коротке зведення: скільки їх усього, скільки мають статуси «Новий», «В роботі» та «Виконано».

Завдання можна:

- шукати за назвою, описом, відповідальним, відділом або статусом;
- фільтрувати за статусом;
- створювати, редагувати та видаляти;
- переглядати разом із відділом, відповідальним і терміном виконання.

Прострочений термін виділяється, якщо завдання ще не виконане й не скасоване. Перед видаленням інтерфейс просить підтвердження.

## Дані завдання та правила

Завдання може містити назву, статус, відділ, відповідального, дату виконання, опис і причину скасування. Статус і відділ вибираються зі списків, а не вводяться довільним текстом.

- Дати зберігаються без часу у форматі `YYYY-MM-DD`.
- Завдання зі статусом «Скасовано» повинне мати причину скасування.
- Причина скасування може містити не більше ніж 250 символів.
- Якщо вказано ID відділу або статусу, він має відповідати наявному запису.
- Відділ, до якого прив’язані завдання, не можна видалити.
- Перелік статусів фіксований: «Новий», «В роботі», «Виконано» і «Скасовано».

Інтерфейс показує зрозуміле повідомлення, якщо сервер відхиляє запит, наприклад коли не вказано причину скасування.

## Відділи та статуси

Списки відділів і статусів завантажуються з API. Назви статусів задані системою й доступні лише для перегляду. Кожне завдання зберігає посилання на ID свого статусу та відділу, тому зміна назви відділу не змінює дані самого завдання.

## Інтерфейс

Вебінтерфейс створено на Angular 19. Запити до сервера виконуються через Angular `HttpClient`. Компоненти бібліотек UI не використовуються: інтерфейс побудований зі стандартних елементів HTML і власного CSS.

Вигляд адаптується до телефона:

- таблиця завдань перетворюється на зручні картки;
- форма редагування відкривається як панель знизу екрана;
- пошук, фільтри й кнопки перебудовуються для вузького екрана.

## Сервер і база даних

ASP.NET Core API обробляє запити, перевіряє дані та зберігає їх у PostgreSQL через Entity Framework Core. Ідентифікатори завдань, статусів і відділів — UUID.

Під час першого запуску на порожній базі API створює таблиці й завантажує приклади з CSV-файлів у `testData`. Якщо таблиці вже містять дані, імпорт пропускається, щоб не замінювати їх прикладами.

У репозиторії не залишено EF Core migrations. Тому автоматичне створення схеми під час першого запуску призначене для нової порожньої бази даних; воно не оновлює структуру вже створеної бази.

## Де шукати код

- API для завдань: `Controllers/CrmTaskController.cs`
- API для відділів: `Controllers/DepartmentController.cs`
- API для статусів: `Controllers/StatusController.cs`
- Моделі й правила даних: `Models/`
- Налаштування таблиць: `Data/CrmDbContext.cs`
- Створення таблиць і початкове завантаження CSV: `Data/CsvDataInitializer.cs`
- Angular-екран: `frontend/src/app/app.component.*`
- HTTP-запити Angular: `frontend/src/app/crm-api.service.ts`
- Документація маршрутів API та приклади запитів: [API.md](./API.md)
- Інструкція зі встановлення й запуску: [README.md](./README.md)

## Технологічний стек

- **Backend:** ASP.NET Core 10, C#
- **База даних:** PostgreSQL
- **Frontend:** Angular 19, TypeScript, Angular `HttpClient`, HTML і власний CSS
